in this folder the Quadratic Discriminant Analysis (QDA) method for classification is investigated for raw audio and sensor dataset.

with this method, the raw audio gives 57, 83 (test, train) accuracies, while the sensor dataset gives 38, 71 (test, train) accuracies. As it shows, the testing accuracy drops compare to LDA method, and also there is big gap between train and test (overfiting).
